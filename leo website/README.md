# Leo's Personal Website

A responsive single-page portfolio built with HTML, CSS, and JavaScript.

## Source files

The complete website source is `index.html`, `styles.css`, `script.js`, and the referenced files under `assets/`. The downloadable portfolio archive is `downloads/leo-personal-website-source.zip`.

The Java expense-tracker project source is not present in this workspace. Keep that source in its own repository (for example, `2336805979-byte/student-expense-tracker-java`) and only add a website link or ZIP download after the repository and archive are public and verified. The portfolio ZIP contains website source, not Java application source.

## Local preview

Open `index.html` in a browser or use the VS Code Live Server extension.

## Assets

The pet photo belongs at `assets/pet-avatar.jpg`; the interest photos belong in `assets/interests/` using the filenames referenced in `index.html`. Keep images optimized for the web.

## GitHub Pages

The account's existing user-site repository is `2336805979-byte/2336805979-byte.github.io`, served at `https://2336805979-byte.github.io/`. To publish this workspace version, place the contents of this folder at the repository root and enable Pages from the `main` branch root in the repository's Pages settings. The deployed page only changes after those files are pushed to GitHub.
